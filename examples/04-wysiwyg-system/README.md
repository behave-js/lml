# Example 04 — LML Workbench layout

This example documents the layout of the LML workbench itself as an LML + Markdown pair.

- [slide.lml](slide.lml): source editor, canvas, and sidebar geometry
- [slide.md](slide.md): content, responsive layout rules, states, and interactions
- [Runnable workbench](../../wysiwyg/): the React implementation

The workbench wireframe preview renders the *target LML document* under edit, not this example's own full semantic interface. The LML file describes a nominal artboard; the Markdown file records responsive constraints and behavior.

The example is a design sketch and is not generated from the React application.
